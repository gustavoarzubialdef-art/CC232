# Uso del proyecto

## Compilación
```bash
cd ARZUBIALDE_GUSTAVO_pc2
cmake -S . -B build
cmake --build build
```

## Ejecutar el programa principal
```bash
./build/sliding_window_maximum
```

## Ejecutar la demo
```bash
./build/demo_sliding_window_maximum
```

## Ejecutar el benchmark
```bash
./build/benchmark_sliding_window_maximum
```

## Ejecutar las pruebas
```bash
./build/test_sliding_window_maximum
```
